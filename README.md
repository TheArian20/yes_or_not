# Para Luz ♡

Una sorpresa de amistad inspirada en el video de referencia: gatitos, mensajes juguetones, un botón «Sí» que crece y una celebración con una dedicatoria para Luz.

## Abrir y compartir

Abre `index.html` con tu navegador. Todo está incluido en ese archivo: estilos, imágenes y el gatito animado. Funciona sin internet, sin instalar nada y sin recopilar datos.

## GitHub Pages

Sube **index.html** a la raíz de tu repositorio. En la configuración de GitHub Pages, publica desde la rama que contiene el archivo y la carpeta raíz. No necesitas instalar paquetes ni configurar un proceso de compilación. También puedes enviar directamente el HTML a Luz.

## Personalizar

Edita los textos directamente en `index.html`. Las imágenes están incrustadas como datos; no necesitas modificarlas para cambiar la dedicatoria.

Los botones funcionan con ratón, pantalla táctil y teclado. El «Sí» crece hasta un tamaño limitado, el «No» permanece disponible y el enlace final permite reiniciar la sorpresa. Se respeta la preferencia de reducir movimiento.

Las imágenes de los gatitos se recortaron del video proporcionado por el usuario. No se incluye la música del video.
